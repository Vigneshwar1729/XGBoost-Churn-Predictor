## 🛠️ TECH STACK
### Core Languages
*   Python 3.11
*   TypeScript
*   HTML5 / CSS3 (Glassmorphism UI)

### Machine Learning & Deep Learning
*   **XGBoost (v2.0.3):** Traditional gradient boosting for tabular data.
*   **PyTorch (v2.14.0+cpu):** Deep learning framework powering the FT-Transformer.
*   **PyTorch Tabular (v1.2.0):** Neural Network architecture specifically designed for tabular datasets.
*   **Scikit-learn / Pandas:** Data preprocessing, scaling, and metric evaluation.

### Backend Infrastructure (API)
*   **FastAPI (v0.110.0):** High-performance Python web framework.
*   **Uvicorn:** Lightning-fast ASGI server.
*   **Pydantic:** Strict data validation schema enforcement.

### Frontend Infrastructure (UI)
*   **React 18:** Component-based architecture.
*   **Vite:** Ultra-fast frontend build tool.

### DevOps & Cloud Deployment
*   **Docker:** Containerization of the Python backend (with explicit PyTorch CPU configurations to optimize RAM).
*   **Render:** Free cloud platform hosting both the Web Service (API) and Static Site (React).
*   **Git / GitHub:** Version control and continuous deployment (CI/CD) pipelines.
*   **cron-job.org:** Keep-alive ping scheduler to eliminate cold-start server latency.
